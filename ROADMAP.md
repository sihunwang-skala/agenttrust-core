# Roadmap (high level)

Directions only; no schedule or commitment.

1. Stronger user authorization: user-signed delegations instead of the demo approval click.
2. Tamper-evidence beyond a single operator (external anchoring, independent witnesses, key management).
3. Authentication, authorization, tenant isolation and rate limiting.
4. Robust handling of crashed or ambiguous merchant calls; a production-grade database.
5. Real merchant and payment adapters, only in sandbox form and only after legal review.
6. Agent framework integrations (e.g. LangGraph, MCP) through the existing adapter interface.

No compatibility with external standards (including AP2) is claimed or planned until it is implemented and verified.
